# 書面文件清理工具 (Document Cleaner)

掃描文件批次清理：**去除小髒點 + 文字轉正**，可選**左右置中**與**1-bit 黑白輸出**。

> **不做 OCR、不重打字、不改字體** — 純影像處理，原文字一個像素都不動。

支援 **PDF / JPG / PNG**，輸出維持原格式。專為複印機 / 掃描器產出的「無內嵌文字層」文件設計。

---

## 功能特色

- **智慧去髒點** — 兩階段連通元件分析，只清孤立小髒點；內建「細字細線保護」，不會把細筆畫、細線、虛線、標點誤殺。
- **文字自動轉正** — 投影輪廓變異數法，±5° 範圍內偵測傾斜並幾何旋轉校正。
- **強制左右置中** — 內容偏一邊時，自動平移到頁面正中央。
- **多種輸出** — 彩色 / 灰階（省記憶體）/ 1-bit 純黑白（檔案最小）。
- **三種使用方式** — 手機瀏覽器（網頁版）、桌面圖形介面、命令列。
- **記憶體友善** — PDF 逐頁處理、即時釋放，舊機器 / 大檔也能跑。

### 1️⃣ 網頁版（推薦給非工程使用者，手機 / 平板也能用）

在一台 Mac 上開伺服器，同 WiFi 的任何裝置用瀏覽器即可使用，**對方完全不用裝任何軟體**。


> 詳細的防火牆 / 連線排除步驟見 [`使用說明.txt`](使用說明.txt)。

### 2️⃣ 桌面圖形介面（批次處理整個資料夾）

```bash
python main.py
```

選輸入資料夾 → 選輸出資料夾 → 按「開始處理」，會遞迴處理資料夾內所有 PDF / JPG / PNG。

```bash
python image_processor.py  輸入圖.png   輸出圖.png
python pdf_processor.py    輸入.pdf     輸出.pdf   [DPI]
```

## 處理選項

| 選項 | 說明 | 介面位置 |
|------|------|----------|
| **去髒強度** | `不去髒`（只轉正/置中）/ `輕度` / `中度（推薦）` / `較強` | 網頁版、GUI |
| **強制左右置中** | 內容一律平移到頁面正中央（忽略最小位移門檻） | 網頁版、GUI |
| **PDF 解析度 (DPI)** | 渲染解析度。網頁版 150/200/300；GUI 100–600 | 網頁版、GUI |
| **省記憶體（強制灰階）** | 黑白文件無差別，記憶體用量約 1/3 | GUI |
| **1-bit 黑白輸出** | 純文字掃描檔最佳，檔案最小（PNG） | GUI |
| **JPEG 品質** | 60–95 | GUI |

> 去髒強度與置中均對 PDF 與圖片一致生效。`不去髒` 適合「掃描很乾淨，只想轉正/置中」的場景。

## 處理原理

### 去髒點（兩階段 + 上下文保護）

1. **Otsu 二值化** 找出深色像素（文字 + 髒點都是深點），**連通元件分析**。
2. **第一階段**：移除「面積小、寬高都小」的孤立小元件。移除前再過兩道保護，避免誤殺細字細線：
   - **細物保護** — 厚度 ≤1px（依 DPI 自動放大）的細長碎片視為細線/細筆畫，保留。
   - **鄰近保護** — 元件只要有任一像素緊貼「字/線主體」（距離 4px，依 DPI 放大）就保留 → 保護字筆畫、字的點、斷裂的細線段。
3. **第二階段**：清除「離文字遠的中等大小孤立髒點」（質心不在文字膨脹區內者）。
4. **自動 scale** — 閾值以 200 DPI A4（~2200px 高）為基準，依影像高度自動放大，讓 200 / 300 / 600 DPI 有一致的視覺去髒效果。

> 判定核心：只有「**又小、又離內容遠、又不是細長**」的元件才會被當真髒點清掉。標點、細字、細線因為一定靠近內容或本身細長，都會被保護。

### 文字轉正

投影輪廓變異數法：文字水平排列時，每行黑像素總和的變異數最大。在 ±5° 範圍內以 0.5° 粗掃 + 0.1° 細掃找最佳角度，再做純幾何旋轉（白色填背景，畫布不放大）。**不改文字內容、不做 OCR。**

### 左右置中

找出有內容的最左 / 最右欄形成 bounding box，計算平移量把它移到頁面水平中央。`強制置中` 模式忽略「位移過小就不動」的門檻。

## 專案結構

```
clean_doc_tool/
├── image_processor.py   影像處理核心：去髒點 + 細字保護 + 轉正 + 置中
├── pdf_processor.py     PDF 逐頁渲染 → 清理 → 重組（記憶體最佳化）
├── main.py              Tkinter 桌面 GUI（批次資料夾處理）
├── web_server.py        Flask 網頁版伺服器（手機 / 平板 / 區網）
├── requirements.txt     依賴套件
├── 啟動網頁版.command    Mac 一鍵啟動（自動建立 .venv）
├── 使用說明.txt          網頁版完整操作說明 + 常見問題
└── 打包步驟.txt          打包 Windows .exe 的步驟
```

---

## 安裝 / 開發

```bash
pip install -r requirements.txt
python main.py        # 桌面版
# 或
python web_server.py  # 網頁版
```

依賴：`PyMuPDF`、`opencv-python`、`numpy`、`Pillow`、`Flask`
（`requirements.txt` 內版本上限刻意保守，以維持 Windows 8.1 / Win10 1507 相容。）
