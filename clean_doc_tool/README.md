# 書面文件清理工具 (Document Cleaner)

掃描文件批次處理：去除小髒點 + 文字轉正，**不修改原文字、不做 OCR**。

支援 PDF / JPG / PNG，輸出保持原格式。

## 下載打包好的 .exe

進入 [Actions](../../actions) → 最新一次成功的 build → 下方
**Artifacts** 區可下載 `DocCleaner-Windows`，內含 `DocCleaner.exe`。

雙擊即可使用，**Windows 端不需安裝 Python**。

## 開發者

```bash
pip install -r requirements.txt
python main.py
```
