書面文件清理 — 網頁版
功能：去除掃描檔的小髒點 + 把歪斜文字轉正
不會修改原文字、也不做 OCR
════════════════════════════════════════════════════════════

支援格式：PDF / JPG / PNG
輸出格式：與輸入相同 (PDF→PDF、JPG→JPG、PNG→PNG)


┌──────────────────────────────────────────────────────────┐
│  使用模式：在 Mac 跑伺服器 → 使用者用瀏覽器連線使用       │
│                                                          │
│  優點：使用者完全不用裝任何軟體                          │
│        舊 Windows、iPhone、iPad、平板都能用              │
│        所有處理都在 Mac 端做，不耗使用者裝置效能         │
└──────────────────────────────────────────────────────────┘


─────────────────────────────────────────────────────────
■ 你 (持有這台 Mac 的人) 要做的事
─────────────────────────────────────────────────────────

   1. 把整個 clean_doc_tool 資料夾放在桌面或下載夾

   2. 雙擊「啟動網頁版.command」

      ★ 第一次雙擊 macOS 可能會擋下來：
        「無法打開，因為它來自身分不明的開發者」
      解法：開啟「系統設定 → 隱私權與安全性」
            找到下方「.command 已被封鎖」按「強制打開」
            或對檔案按右鍵 → 選「打開」→ 再按「打開」

      ★ 第一次需要網路約 1-3 分鐘建立 Python 環境

   3. 終端視窗會印出兩個網址，類似這樣：

         本機網址 (在這台 Mac 上用):
             http://127.0.0.1:8765/

         區網網址 (給手機 / 其他電腦用):
             http://192.168.1.10:8765/    ← 你的數字會不同

   4. 把「區網網址」那行用 LINE / 簡訊傳給要使用工具的人

   5. 不要關掉終端視窗。要結束時按 Ctrl+C 或直接關掉。


─────────────────────────────────────────────────────────
■ 使用者 (要清理檔案的人) 要做的事
─────────────────────────────────────────────────────────

   1. 確認自己的裝置 (手機 / 平板 / Win 電腦) 跟你的 Mac
      連同一個 WiFi

   2. 打開瀏覽器 (Safari / Chrome / Edge 都行)
      在網址列輸入你給的網址，例如:
           http://192.168.1.10:8765/

   3. 出現上傳介面：
         ‧ 點「選擇檔案」→ 選 PDF / JPG / PNG
         ‧ 強度選「中度 (推薦)」
         ‧ 按「開始處理」

   4. 處理完成後出現綠色「下載清理後的檔案」按鈕
      點下去檔案會存到「下載」資料夾。


─────────────────────────────────────────────────────────
■ 常見問題
─────────────────────────────────────────────────────────

  Q: 使用者的瀏覽器打不開那個網址 ?
  A: 三個方向逐一檢查：

   (a) 兩台裝置真的在同一個 WiFi 嗎？(別用行動數據)
       使用者手機看 WiFi 名稱，跟你 Mac 的 WiFi 名稱對一下。

   (b) 你的 Mac 防火牆是不是擋了：
       系統設定 → 網路 → 防火牆
       第一次跑會跳「python3 是否接受傳入連線」對話框，
       一定要按「允許」。
       或暫時關掉防火牆測試。

   (c) IP 變了 (Mac 換到別的 WiFi 後 IP 會變)。
       重新雙擊「啟動網頁版.command」會印出新的網址。

  Q: 終端視窗印出 [錯誤] 套件安裝失敗 ?
  A: 你 Mac 沒網路。確認連線後重跑「啟動網頁版.command」。

  Q: 上傳超過 100MB 的大檔案？
  A: 開 web_server.py 改 MAX_UPLOAD_MB = 200 之類。

  Q: 想結束伺服器？
  A: 在終端視窗按 Ctrl+C，或直接關掉視窗。

  Q: 我換了 WiFi，網址會變嗎？
  A: 會。只要重啟「啟動網頁版.command」會印出當下的新網址。

  Q: 想完全移除工具？
  A: 直接刪除 clean_doc_tool 整個資料夾即可。


─────────────────────────────────────────────────────────
■ 處理原理 (技術細節)
─────────────────────────────────────────────────────────

去髒點：Otsu 二值化 → 連通元件分析 → 只移除「面積 ≤ 8 像素
        且 寬/高都 ≤ 3 像素」的元件。在 200 DPI 下中文最小
        標點 (、) 面積至少 30+，所以這個閾值非常安全。

文字轉正：投影輪廓變異數法。±5° 範圍內 0.5° 粗掃 + 0.1° 細掃。
        純幾何旋轉，不會改文字內容、不會 OCR。
