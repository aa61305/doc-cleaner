════════════════════════════════════════════════════════════
  用 GitHub Actions 雲端產出 DocCleaner.exe
  (在你 Mac 操作，5-10 分鐘搞定)
════════════════════════════════════════════════════════════


─────────────────────────────────────────────────────
■ 第 1 步：註冊 GitHub 帳號 (如果還沒有)
─────────────────────────────────────────────────────

   1. 開瀏覽器到  https://github.com/signup
   2. 用你的 email 註冊 (免費)
   3. 收信認證 email


─────────────────────────────────────────────────────
■ 第 2 步：建立新的 Repository
─────────────────────────────────────────────────────

   1. 登入後，右上角點 ＋ → 「New repository」

   2. 填寫：
        ‧ Repository name: doc-cleaner  (隨便取都可以)
        ‧ Description:     (留空也行)
        ‧ 選 Public  (Private 也行，Public 比較方便)
        ‧ 不要勾任何「Initialize with」選項

   3. 按綠色 「Create repository」


─────────────────────────────────────────────────────
■ 第 3 步：上傳整個 clean_doc_tool 資料夾
─────────────────────────────────────────────────────

   1. 在剛建好的空 Repo 頁面，
      點藍色文字「uploading an existing file」

   2. 進到上傳頁面後，
      把 clean_doc_tool 資料夾「裡面」的所有檔案
      (不是整個資料夾喔，是裡面的內容) 全選後
      ★ 拖曳放到網頁上的虛線框內 ★

      要拖的檔案包括：
        ‧ main.py
        ‧ web_server.py
        ‧ image_processor.py
        ‧ pdf_processor.py
        ‧ requirements.txt
        ‧ README.md
        ‧ .gitignore
        ‧ .github 整個資料夾 (含裡面的 workflows/build.yml)
        ‧ 使用說明.txt
        ‧ 啟動網頁版.command

      ※ .github 資料夾比較容易漏掉，記得拖進去！

   3. 拖好之後最下面 Commit message 寫個「Initial」也可以
      留空。直接按綠色「Commit changes」。


─────────────────────────────────────────────────────
■ 第 4 步：等 Actions 自動打包
─────────────────────────────────────────────────────

   1. Repo 上方有「Actions」分頁，點進去

   2. 看到一個正在跑的 workflow「Build Windows EXE」
      (黃色圓點 = 進行中、綠色勾 = 完成)

   3. 等它跑完，約 5-10 分鐘
      (第一次 GitHub 可能會問你要不要啟用 Actions，按確認)


─────────────────────────────────────────────────────
■ 第 5 步：下載 DocCleaner.exe
─────────────────────────────────────────────────────

   1. 點那個跑完的 workflow 紀錄

   2. 滾到頁面最下方有「Artifacts」區塊

   3. 點 「DocCleaner-Windows」下載 zip

   4. 解壓 zip 拿到 DocCleaner.exe (約 150MB)

   5. ★ 把這個 .exe 用 LINE / 任何方式傳給使用者 ★

   6. 使用者拿到 .exe 直接雙擊即用 ──
      不用解壓、不用 .bat、不用 Python、什麼都不用裝
      只要他的 Windows 不是太古老 (Win 8.1 或以上即可)


─────────────────────────────────────────────────────
■ 之後改程式怎麼辦
─────────────────────────────────────────────────────

  你 Mac 上修了任何 .py 檔，把改過的檔案丟到 GitHub:
   1. 在 Repo 找到那個檔案 → 右上角鉛筆圖示 → 改完按 Commit
   2. 或整批：右上角「Add file」→「Upload files」→ 拖上去

  Push 之後 Actions 會自動再跑一次，產出新版 .exe。


─────────────────────────────────────────────────────
■ 出問題排除
─────────────────────────────────────────────────────

  Q: Actions 沒跑起來?
  A: Repo → Settings → Actions → General
     確認「Allow all actions and reusable workflows」有勾。

  Q: Actions 跑失敗 (紅色叉)?
  A: 點進失敗的 run，看哪個步驟紅色。
     截圖那個錯誤訊息給我，我看 build.yml 是不是要改。

  Q: 找不到 .github 資料夾?
  A: macOS Finder 預設隱藏「.」開頭的資料夾。
     開啟 Finder 後按 Cmd + Shift + . (句點) 切換顯示。
